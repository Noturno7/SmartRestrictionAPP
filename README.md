# SmartRestrictionAPP
BR 🇧🇷
Desenvolvimento e publicação do meu aplicativo de anotações: Smart Restriction
Dado o aumento das informações de facil acesso e a facilidade da fácilidade da compra de dopamina fácil o ser humano tem se tornado cada vez mais distraido, com isso pensei nessa aplicação para priorizar suas tarefas e compromissos de forma simples e eficiênte, de forma que o usuário sem distrações consiga organizar e fazer suas atividades de maior prioridade antes de se voltar para qualquer outra coisa. Ele deve ser utilizado como um guia diário, todos os dias sendo atualizado com novos compromissos e anotações, até mesmo de estudos, com seu design simples é feito para não chamar muito sua atenção, mas mais ser como um caderno pessoal diário.
O nome veio dessa ideia, uma restrição inteligente feita pelo usuário, para priorizar sua energia e dopamina para as coisas certas. 
Qualquer atribuição ou contribuição estarei sempre disponível para ouvir novas ideias, ainda planejo adicionar novas funcionalidade, mas estou contente com a versão final deste projeto.

ENG 🇺🇸
Development and publication of my note-taking app: Smart Restriction
Given the surge in easily accessible information and the ease of obtaining "quick dopamine hits," humans have become increasingly distracted. With this in mind, I created this application to help prioritize tasks and commitments in a simple, efficient way—allowing users to organize and complete their highest-priority activities without distractions, before moving on to anything else. It is intended to serve as a daily guide, updated each day with new commitments and notes—including study-related material. Its design is intentionally understated, avoiding unnecessary visual clutter so that it functions more like a personal daily notebook.
The name stems from this concept: an "intelligent restriction" set by the user to focus their energy and dopamine on the things that truly matter.
I am always open to feedback or contributions and welcome new ideas. While I plan to add further features, I am very pleased with the final version of this project.
